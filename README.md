# 湖北国土资源职业学院 · 三维交互校园

> 依据学校官方网站公布的《校园地图》重建的 three.js 三维校园交互页面。
> 纯静态、离线可运行：**双击 `index.html` 即可**（无需服务器、无需联网）。

![三维校园](shots/overview.png)

## 一键打开

在 Windows 资源管理器中双击 `index.html`，使用新版 Chrome / Edge 打开即可。
页面内所有 three.js、纹理与数据均为本地资源，不会发起任何网络请求。

> 如果浏览器提示本地文件限制，可在本目录执行 `python -m http.server 8080`，
> 再访问 `http://localhost:8080/`。

## 功能

- **三维校园**：中央环形教学区、图文信息中心、实验/教学大楼、体育馆、多功能厅、学生宿舍、食堂、田径场、看台、球类场地、学术交流中心、教师公寓、水杉林、马影河、坛山岛湿地等。
- **自由漫游**：拖动旋转、滚轮缩放、右键平移，支持触屏单指旋转、双指缩放。
- **地标交互**：18 个 POI 标注与信息卡；点击建筑或列表可飞行定位，附官方资料来源。
- **自动导览**：8 站镜头巡游（东门礼仪轴 → 图文信息中心 → 中央教学区 → 运动区 → 生活区 → 马影河 → 夜景），支持暂停/切换。
- **昼夜光影**：白昼 / 夜景一键渐变，夜间窗户逐栋点亮、路灯与萤火虫出现，支持自动昼夜循环。
- **场景图层**：建筑 / 绿化 / 水系 / 交通人物 / 地标标注独立开关。
- **动态细节**：环形道路车辆、校园行人、地铁 16 号线列车、校旗飘动、水流与云影。
- **校情速览**：学校简介、办学坐标、校训校风、发展亮点与资料来源。
- **开场动画 + 加载页 + 响应式 UI**：适配桌面与手机；`?shot=1&view=overview` 等调试参数。

## 数据与建模说明

- 校园布局、建筑位置与道路水系依据学校官网 **《校园地图》**（`assets/campus-map.jpg`）逐块重绘；
  图文信息中心 12 层 / 17783 ㎡ 等信息来自学校公开资料。
- 地形与校园总平面被处理为一张可直接叠加三维建筑的手绘风地表（`scripts/build_scene.py` 自动生成）。
- 建筑由 `js/buildings.js` 程序化生成（11 种建筑风格，全部 Canvas 纹理，无外部模型）。
- “预留发展”“学生宿舍预留用地”等地块按官方规划图保留为空地，未擅自建成实体建筑。
- 三维表达为**艺术化处理，非精确测绘**；建筑体量、广场与植被密度经过美化。

```

css/style.css              UI 样式
js/data.js                 校园数据（建筑 / POI / 导览 / 校情）
js/buildings.js            程序化建筑生成模块
js/scene.js                场景构建（地表 / 水系 / 天空 / 植被 / 交通 / 人物）
js/app.js                  相机控制 / 交互 / 导览 / 昼夜 / UI
js/ground-tex.js           地表纹理（base64 内嵌，由脚本生成）
js/ground-data.js          树木点位 / 水面遮罩 / 校园边界（由脚本生成）
vendor/three.min.js        three.js r159（本地）
assets/                    校徽、官方校园图、生成的地表与水遮罩
scripts/                   数据处理与自动化截图脚本（开发用）
shots/                     无头浏览器渲染的验证截图
research/facts.md          学校事实资料与来源清单（25 条 URL）
```

## 技术

- three.js r159（UMD，本地引入），全部纹理 Canvas 程序化生成或 base64 内嵌；
- 无构建步骤、无运行时依赖、无网络请求；
- 渲染统计（桌面 1440×880）：约 600 draw calls / 28 万三角面，带帧率自适应降采样。
